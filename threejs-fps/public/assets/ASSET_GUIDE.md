# Pasta de recursos do Tactical Strike

## Armas 3D

Adicione os arquivos GLB em `weapons/`: `rifle.glb`, `pistol.glb` e `at4.glb`.

## Imagens de interface

Os SVGs em `icons/` são imagens provisórias que já aparecem no HUD. Podem ser substituídos por PNG/WebP com fundo transparente, mantendo os mesmos nomes-base e atualizando as extensões no código se necessário.

- rifle.svg / rifle-ammo.svg
- pistol.svg / pistol-ammo.svg
- at4.svg / rocket-ammo.svg
- grenade-ammo.svg

Use imagens próprias ou assets com licença que permita uso e redistribuição no jogo.
