# Modelos 3D das armas

Coloque aqui os modelos GLB com estes nomes exatos:

- `rifle.glb` — fuzil de assalto
- `pistol.glb` — pistola
- `at4.glb` — lança-foguetes AT-4

O jogo detecta os arquivos automaticamente e os usa na visão em primeira pessoa. Para melhor encaixe, exporte cada arma com o cano apontando para o eixo local **-Z**, escala em metros e origem próxima à empunhadura. O jogo mantém o modelo procedural atual como fallback quando o GLB ainda não existir.
